# 图片查看器示例

这一层没有开关：注册之后，凡是正文里有图片的文档页，那些图片都归查看器管。

![主题层栈：谁包着谁](/img/viewer-demo.svg)

点开上面这张图，查看器在顶层打开：放大、缩小、原尺寸、重置各一颗按钮，标题用的是图片的
说明文字（`alt`）。

![一份文档源到页面，中间经过哪几步](/img/viewer-flow.svg)

同一页的多张图进的是同一个图集，所以从任意一张都能往前后翻到另一张。

正文里没有图片的页面（例如侧栏里其余那几页）不会加载查看器，这一层对它们是透明的。
