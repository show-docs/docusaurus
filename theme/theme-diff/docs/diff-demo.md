# 差异视图示例

这一页的 frontmatter 写的是 `diff: ../../../docs/intro.md`，所以上方那块视图对比的是主页
`docs/intro.md` 的上一个版本与现在这一份 —— 指向别的文件也可以，路径相对这份 md 所在的目录算
（视图上方显示的那一个名字是仓库相对路径，不是这里写的那一串 `../`）。

写 `diff: true` 就是对比本文自己。

右边那一格永远是磁盘上此刻这一份，左边是它的上一个版本：工作区里还有没提交的改动时，左边就是
这份文件上一次被提交的那一版；已经提交干净时，左边往前再取一次属于这份文件的改动。视图并排显示，
中间只列出真正变化的那几段，配色跟着站点的亮暗模式走。

没有上一个版本时（这份文件还一次都没提交过，或者提交过一次之后没有再改动），这一页等于没开这个
功能，正文照常渲染。判据与代价记在 `theme/theme-diff/README.md`（站点文档源只收 `docs/`，链接出去
只会是死链）。
